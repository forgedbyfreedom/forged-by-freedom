I don't really set New Year's resolutions, but if I did, I wouldn't set them around a goal, but a habit. So, not what do I want to achieve this year, but what are things I can do every day to get me closer to the things that I want. Now, why is it every day? Number one, it's probably not going to be every day. I'll probably have some off days, but I want to aim for often. And number two, it doesn't have to be the same thing every day. So, if it's around fitness, I don't have to work out every day, but I can read and learn and improve my fitness on my rest days. And number three, I want that slight struggle and discomfort as I'm learning this new habit. Because the truth is for me, if the habit already felt great and automatic, I would probably already have it. So, there's a little bit of struggle cost as I learn to install this new behavior. And I try to learn to embrace a process rather than a goal because I have a little bit more control over the process. But if goals motivate you, that is awesome. Have a beautiful day.

The SERS criteria were used to define sepsis for many years. However, we have new definitions now that were postulated by the international work group on sepsis in 2016. So now when we talk about how to define sepsis clinically, we use the sofa criteria. That stands for sequential organ failure assessment. It's a very reliable and valid assessment scheme, but it's really designed to be used sequentially over time in an intensive care unit setting. So, it's not terribly helpful in the emergency department setting because we don't even have access to all of the data that you need to calculate the sofa right up front. So in the EG we use the Q sofa where the Q stands for quick.

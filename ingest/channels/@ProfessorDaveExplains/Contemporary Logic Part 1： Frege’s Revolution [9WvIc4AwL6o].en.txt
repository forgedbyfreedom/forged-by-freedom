So, how great was this revolution? Let’s take\h\h the first example we used in this series: “All\h YouTubers are mortal/Dave is a YouTuber/Thus, Dave\h\h is mortal”. As we’ve seen, we can represent this\h with Darii, or AII mood sentence, as “Every Y →\h\h M/D → Y/Therefore, D → M”, or in contemporary\h form, “Aym, Idy ⊢ Idm”. When we\h\h assign information to this variable, such as “x\h is a YouTuber”, we represent it by setting a “Y”,\h\h next to it, or “Yx”. Another bit of information\h that lies in this first proposition is that if x\h\h is a YouTuber, x is mortal. Now,\h if we were to represent the entire original modus\h\h ponens, we’d have to identify that variable,\h as we’d be talking about a specific individual,\h\h or me, Dave. Let’s use the first letter of my name\h then. The second proposition would become “Yd”.\h\h Now it’s quite straightforward. ∀x(Yx → Mx)/Yd ⊢\h Md. Translating Frege’s logical language, we get\h\h something like: “Regarding all values of x [∀x],\h if x is a YouTuber, x is mortal [Yx → Mx]. Dave\h\h is a YouTuber [Yd], therefore [⊢ or a line below]\h Dave is mortal [Md]”. This formulation allowed for\h\h a much wider range of action than Aristotelian and\h even the binary Boolean formulations – one of the\h\h many manners in which Frege revolutionized logic. Frege’s training as a mathematician is clear,\h\h especially if we compare this example to\h advanced arithmetic formulas where variables\h\h wholly take over the usage of numbers.

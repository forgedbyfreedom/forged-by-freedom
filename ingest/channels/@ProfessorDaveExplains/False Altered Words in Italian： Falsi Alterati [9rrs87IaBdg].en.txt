Professor Dave again, let’s look at false altered words. Way at the beginning of this course, we learned about cognates, as well as all the false cognates that can be tricky to remember. Similarly, since we just learned about altered words and the suffixes that generate them, we have to also learn about false altered words. These are words that present the same suffixes we just learned, but they have a meaning that is totally independent of these altered words. For example, fumo means smoke. If we then see the word fumetto, we might think that it means cute little smoke. But it doesn’t, it actually means comic book. The derivation of this word stems from the fact that in a comic book, the words are written inside little clouds, perhaps clouds of smoke, but nevertheless, the ending of this word does not make this an altered word, it is a completely separate word unto itself. There are many such words, so let’s go through the most common ones so that you won’t get fooled again. In each case, we will show a pair of words where it seems like the second one would be an altered version of the first, but in fact, their meanings are totally unrelated. So that’s all there is to it, and if we can remember all of these false altered words, we won’t mix them up and say something foolish in conversation. Let's check comprehension.

data properties to visual properties data properties are usually numerical or categorical like the mean of a variable the maximum value of a variable or the number of observations with a certain property visual properties can be XY coordinates to plot points on a graph colors to assign labels sizes shapes Heights etc both types of properties are used to better understand the data but in different ways to motivate the need for data visualization let's look at a famous example called ants combs quartet each of these tables corresponds to a different data set we have four data sets each
